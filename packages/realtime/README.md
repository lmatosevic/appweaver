## Description

`@appweaver/realtime` pushes events to the clients of an [Appweaver](https://github.com/lmatosevic/appweaver) API over
a WebSocket or Server-Sent Events, a module enabled by installing it (it requires `@appweaver/web`). The clients
subscribe to:

- the **channels** of the application and of the modules, created with `createChannel`
- the **resource events** (`create`, `update`, `delete`) of the models exposing them with `createRoutes({ events })`

and call the custom **actions** of `createRealtimeAction` over the WebSocket, waiting for the result or
fire-and-forget. Nothing is exposed unless declared, and every event is checked against the access of the subscribed
user: the callbacks of the channel, or the `events` callback of the resource policy, else its `checkAccess` and
`readRestrictions`. With `@appweaver/redis` the events reach the connections of every instance through the Redis
pub/sub.

## Installation

```sh
npm install @appweaver/realtime
```

or `weaver module add realtime` in a project created with `@appweaver/create`.

## Usage

```ts
import { Type } from '@sinclair/typebox';
import { createChannel, createRealtimeAction } from '@appweaver/realtime';

export const orderShipped = createChannel({
  name: 'order.shipped',
  payload: Type.Object({ orderId: Type.Integer(), customerId: Type.Integer() }),
  deliver: (user, payload) => payload.customerId === user?.id
});

createRealtimeAction({
  name: 'chat.typing',
  payload: Type.Object({ roomId: Type.Integer() }),
  handler: async ({ roomId }, { user }) =>
    typing.publish({ roomId, userId: user!.id })
});

await orderShipped.publish({ orderId: 7, customerId: 1 });
```

The client generated by `weaver-client generate` connects with a ticket of `POST /api/realtime/ticket`:

```ts
client.realtime.subscribe('order.shipped', (payload) => console.log(payload));
client.realtime.on('Order', (event) =>
  console.log(event.action, event.current)
);
await client.realtime.send('chat.typing', { roomId: 1 });
```

See the [realtime reference](https://github.com/lmatosevic/appweaver/blob/main/skill/references/realtime.md) for the
protocol, the config and the limits.
